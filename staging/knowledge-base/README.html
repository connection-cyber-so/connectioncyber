Gates de CONTEÚDO (distintos dos gates de desenvolvimento): M0 Entrada → M1 Classificação → M2 Aplicação → M3 GitHub → M4 Liberação. Nova revisão retorna a M0; revisão otimista e bloqueio de linha impedem aprovação concorrente obsoleta. Autor não libera seu próprio material. Histórico e auditoria append-only para clientes.
