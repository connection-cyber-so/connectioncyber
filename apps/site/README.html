apps/site — Site Corporativo ConnectionCyber

Tecnologia que traz conhecimento e gestão. Site institucional, portal de pagamentos, área de membros e mapa arquitetural enterprise. Faz parte do monorepo connectioncyber, ao lado de apps/platform e packages/core.

✅ Pronto e funcionando

  • Site institucional completo (Home, Sobre, Serviços, Cursos, Produtos, Clientes, Contato, Sistema, Checkout, retorno de pagamento)
  • Identidade visual oficial — logo real e paleta de marca oficial em src/styles/theme.css
  • i18n PT-BR/EN-US via Context API (sem biblioteca externa) — i18n nativo do Next.js removido (causava NOT_FOUND na Vercel)
  • /login funcional + middleware de proteção de rota (src/middleware.ts) — corrige o hang de /membros
  • Autenticação e RBAC via Supabase Auth
  • Pagamentos Mercado Pago (create-preference, webhook, checkout)
  • Schema Supabase completo — 4 migrations aplicadas no projeto real
  • Edge Function lookup-cnpj implantada e testada
  • Sistema Visual Enterprise (mapa com 22 nós, 33 conexões)
  • npm run build validado — 17 rotas, 0 erros

Como rodar localmente

cd F:/Projetos/connectioncyber/apps/site
npm install
cp .env.local.example .env.local
npm run dev

Abra http://localhost:3000. Funciona sem nenhuma credencial preenchida (modo demonstração).
