Parecer técnico M23 · diagrams do modelo atual e das opções · feito para decisão, não para código.

RESPOSTA DIRETA

Hoje cada cliente tem a sua academia, com cursos criados dentro da empresa dele

Um curso hoje pertence a uma única empresa (regra do banco: academy_courses.tenant_id é obrigatório). Ou seja, se você quiser o mesmo curso em 100 clientes, hoje precisa criar 100 cópias — e atualizar 100 vezes. Você não precisa se confundir: dá para inverter isso (curso existe1×, as empresas só “ligam” ele); é a opção B/C lá embaixo, e exige uma mudança no modelo de dados (uma migration nova + tela de catálogo).

3. As 3 formas de ter “o mesmo curso para todos” ESCOLHA

Opção A — como está hoje

Curso copiado por empresa

  • Você cria o curso dentro de cada cliente.
  • 100 clientes = 100 cópias
  • Mudou1 item → refaz em todas
  • Nenhuma mudança de sistema
  • Bom só para poucos clientes e cursos diferentes.
Opção B — recomendada

Catálogo único + “liga/desliga” por empresa

  • O curso existe 1 vez só, na ConnectionCyber.
  • Cada empresa só ativa os cursos que quer oferecer.
  • Atualizou1 vez → todos os clientes veem atualizado
  • 100 clientes = 1 clique para liberar em todos
  • Exige migration nova + tela “Catálogo” na curadoria.
Opção C — híbrida

Catálogo global + cursos próprios do cliente

  • Seus cursos padrão (B) mais cursos que cada cliente cria sozinho.
  • Cliente treina o uso do sistema dele com o curso dele
  • Você treina todo mundo com o seu conteúdo
  • Esforço de implementação um pouco maior que B.

4. Detalhe importante sobre “treinamento do sistema que eu desenvolvi para ele”

Você pode usar a mesma Academia para as duas coisas, sem confusão de marca: (1) cursos seus, gerais (ex.: “Atalhos de teclado”, “Segurança da senha”), liberados a todos; (2) cursos específicos do produto que você entregou àquele cliente (ex.: “Como usar o sistema X da Empresa Y”), criados só naquela empresa — ou também no catálogo, se forem iguais para todos. A separação é feita por categoria (ex.: plataforma x cliente) e pela ativação por empresa.
